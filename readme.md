# Picnic Pioneers

A game about finding the best picnic spot in the universe!

By Tachytaenius and flipfloppy.
Uses the [LÖVE](https://love2d.org/) framework (version 12.0).

The game is entirely threatless. Just make food and explore an enormous in-depth universe :)

It's in early development and not playable yet. It's also currently Linux-only due to not compiling libraries for Windows or MacOS (yet).

## Building

To get the game to be runnable using LÖVE, run `make`.
Dependencies are not listed yet...

The game also uses [makelove](https://github.com/pfirsich/makelove) to package up into AppImages etc.
Makelove doesn't support LÖVE 12.0 yet, though.
